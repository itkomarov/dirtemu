# RX 570 fork adaptations, 2026-11-28

These changes target the CPU stalls, unavailable streamed resources and retained
host copies seen in the last Series S run. They preserve shader translation
and its existing cache. They have not yet been validated in another game run.

The null-event fence behavior follows the
[Microsoft API contract](https://learn.microsoft.com/en-us/windows/win32/api/d3d12/nf-d3d12-id3d12fence-seteventoncompletion).
The external change only partially covered this case, so its incomplete
E_NOTIMPL fallback was not copied.

## Additional local ownership corrections

Completed dynamic ranges now release the resources in their `kept` slots before
the allocator exposes those slots as free. Unrelated title slots and ranges
still owned by other lists remain pinned. Submitting a list whose actual
dynamic ranges have already been released requires a new recording; stale
submissions are rejected before entering the queue. This prevents using freed
resource references through recycled descriptors.

Registered buffers can release a cold host copy while retaining their guest
registration. Pressure reclamation and idle sweeps protect copies with command
list references, descriptor references, pending shader writes or in-place
allocations. Lookups update usage and recreate a discarded copy on demand.
The admission path preserves lock order and uses nonblocking cross-cache locks.

## Controls

- `VICTORY_TEXTURE_STAGE_PER_FRAME=0` restores a per-pass time allowance.
- `VICTORY_TEXTURE_STAGE_US` takes precedence over `VICTORY_TEXTURE_STAGE_MS`.
- `VICTORY_TEXTURE_STAGE_BYTES` takes precedence over `VICTORY_TEXTURE_STAGE_MB`.
- `VICTORY_PIPELINE_WAIT_MS` changes ordinary and default screen waits;
  `VICTORY_PIPELINE_WAIT_SCREEN_MS` changes screen waits separately.
- `VICTORY_PIPELINE_WAIT_ONCE_MS` changes the known bake allowance. The bake
  allowance is never below the ordinary allowance.

## Verification and limits

Tests cover shared budgets across concurrent recorders, charging early returns,
long single operations, stale frame accounting, bake classification, actual
D3D12 reference-count release, wrong heap generations, real Windows page
mappings, WARP copy eviction and preservation of active pins, null fence waits,
CPU rewinds, queue writes, direct Windows address wakeups, and decoded BC7 bits.

The combined run passed 192 GPU tests (one pre-existing ignored test) and
104 HLE tests. The final queue suite then passed all 6 tests, including the
last direct address-wakeup regression. BCPack passed 11 tests with two existing
ignored benchmark/reference-data cases. Strict workspace Clippy across all
targets and features passed. The release executable with Agility was rebuilt
after the final source changes.

Lower time budgets can spread texture streaming and new PSOs across more
frames. They cannot make unsupported shaders render correctly. The previous
GPU timeout and independent AMD compiler fault remain unresolved. No RX 570
FPS improvement or removal of the black screen is claimed from unit tests.

The fault-handler plain-copy path, soft views, descriptor synchronization
rewrite, texture heap allocator, and small readonly card buffers were not
ported. They require separate lifetime and fault-path validation. Shader
sampler/mask patches also remain separate because they change translation and
require a new archive validation and cache preparation pass.
